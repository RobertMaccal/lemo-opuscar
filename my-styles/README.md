# My styles

The user's own Lemo-Opuscar styles, kept in this repository (cloud sessions don't keep `~/lemo-my-styles/`). Use one like a library style: "Make a film in my <name> style about …". Each has a project skill in `.claude/skills/<slug>/`.

| Style | 中文 | Slug | Base | What it is | Folder |
|---|---|---|---|---|---|
| Golden Hour Stickman | 暖光火柴人 | `golden-hour-stickman` | core tools (blank page) | Nostalgic stick-figure sitcom: doodle characters with huge acting faces in warm, window-lit, flat-shaded rooms; vertical 1080×1920 | `my-styles/golden-hour-stickman/` |
| Sketchbook Case File | 速写案卷 | `sketchbook-case-file` | core tools (blank page) | Narrated true-case explainer in a pencil sketchbook: chibi characters, wobbly ink, grey hatching, one yellow accent, taped karaoke captions, verdict-first, case-file zoom-out; vertical 1080×1920 | `my-styles/sketchbook-case-file/` |
