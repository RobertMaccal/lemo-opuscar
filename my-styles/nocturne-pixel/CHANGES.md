# Nocturne Pixel — decisions (from a blank page; technique base `pixel-rpg`)

| Section | Base (pixel-rpg) | Now | Why |
|---|---|---|---|
| §1 Essence | game systems as narrative language (UI, menus) | rainy-night pixel cinema, no UI, mood over plot | the references and the brief: a cut-scene, not a game |
| §1 Grid | 320×180 ×6, 16:9 | 360×640 ×3, 9:16, 30 fps | vertical feeds; enough detail for a character and a miniature |
| §2 Light | index stepping, glows as Bayer rings | same, plus layered parallax, a 4× detail layer and a glass portal | a camera that moves like a film without breaking the pixel look |
| §2 Post | no scanlines, no grain | faint scanline (one per native pixel) + vignette | "subtle CRT-inspired texture" in the brief |
| §3 Colour | palette = feeling, era colour depth | night ramp vs warm ramp; the last light is the brightest warm | the references: blue-black facades, amber windows |
| §4 Type | dialog boxes as subtitles | four title cards, original 5×7 font, Bayer dissolve | no dialogue, no subtitles |
| §5 Motion | sprites on 8–12 fps, integer camera | smooth sub-pixel camera, log-zoom splines; life cycles per window | cinematic movement |
| §6 Camera | side-scroll, battle view, overworld | dolly-in, facade S-pan, push through glass, macro, two-worlds frame, reverse push | — new |
| §7 Sound | chiptune voices with echo | detuned piano, analog pads, drone, FM bells, reversed swells, tape hiss; rain, clicks | nostalgic, mysterious, not chip |
| §8 Native moves | palette collapse, save files, level up | building falls asleep, through the glass, shared light table, lamp dies & floods back, last window wide | the film's own moves |
| §2 Miniature | — | painted wooden-block models (reference 1) | the miniature city in the story |
